# Progress Reports

One file per two-week period, in the format supervisor review meetings need:
what changed, what was decided (and why), current state against the SOW,
and what to raise with Shawna. Keep the most recent report's "Next steps"
section in sync with the following report's "What was done" — that's the
thread reviewers will actually follow.

## Naming

`weeks-NN-NN.md`, numbered from the start of the assistantship (Week 1 =
first week of the 15-week SOW timeline), e.g. `weeks-01-02.md`,
`weeks-03-04.md`. If a period slips (skipped week, holiday, etc.), note it
in the file rather than renumbering.

## Template for a new report

```markdown
# Weeks N-N — <one-line theme>

**Period:** <date> to <date>
**SOW phase:** <Phase N: name, per the SOW's Section 3>

## Summary
2-4 sentences: what's the headline for this period.

## What was done
Concrete, dated list of work completed.

## Decisions made
Anything a reviewer would ask "why did you do it that way" about.
State the decision and the reasoning.

## Current state vs. SOW
Checklist against the relevant phase's duties/deliverables.

## Findings / deviations from the SOW
Anything the original scope-of-work assumed that turned out to be wrong,
with evidence.

## Open items / needs supervisor input
Decisions only Shawna can make, or things worth flagging before they
become a problem.

## Next steps
What's planned for the next period.
```
